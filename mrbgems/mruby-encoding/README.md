# mruby-encoding

This mrbgem is where UTF-8 lives. Carrying it is what has a build read its
strings as characters rather than as bytes, and it is what gives Ruby the
`Encoding` names and the String and Integer methods that ask about them.

## Summary

- **License:** MIT
- **Author:** mruby developers
- **Supported Encodings:**
  - `Encoding::UTF_8`
  - `Encoding::ASCII_8BIT` (aliased as `Encoding::BINARY`)

## What the gem holds

- `src/utf8.c`: the UTF-8 primitives, the walk that counts a string's
  characters and reads whether its bytes spell any, and the conversion between
  a character index and a byte offset.
- `src/unicase.c` and `src/unicase.h`: the Unicode case tables and the lookups
  over them, generated by `tools/gen_unicase.rb`. mruby-regexp reads them for
  its `/i` folding.
- `src/case.c`: the walk that converts a string's case by those tables.
- `src/encoding.c`: the `Encoding` module and the String methods below.

Core's `string.c` keeps the byte-indexed answers a build without the gem gives
instead, and the branches that choose between the two. A few of its own string
primitives are exported for the walks here to build their answers with; they
are declared beside their callers in `include/mruby/internal.h`.

## The define the build branches on

The gem hands the whole build one define, `HAVE_MRUBY_ENCODING_GEM`, and that
is the define core and every other gem branch on. Nothing else defines it:
there is no compile flag that turns UTF-8 on without the gem, and none that
turns it off with it. `MRB_UTF8_STRING`, which used to be that flag, is gone;
a build configuration still spelling it is stopped with an `#error` rather
than quietly built with strings indexed by byte.

`MRuby::Build#has_define?('HAVE_MRUBY_ENCODING_GEM')` is how a gem's
`build_settings` block reads the answer back, which is what mruby-regexp does
to pick between its Unicode and its ASCII test files.

## What carrying it changes

- Character-oriented String methods index by character: `"あ".length` is 1,
  and `String#[]`, `#index`, `#split` and the rest count the same way.
- Case conversion follows Unicode: `String#downcase`, `#upcase`, `#capitalize`
  and `#swapcase` map every character Unicode gives a case, and a mapping may
  spell several characters (`"ß".upcase` is `"SS"`). `String#casecmp?` folds
  by the same data rather than converting.
- A string read as bytes (`String#b`) converts and folds ASCII alone, and one
  holding bytes that spell no character is refused with `ArgumentError`.
- The regexp `i` flag reads the same data, folding every character Unicode
  pairs with one other. Without the gem it folds ASCII letters, and a pattern
  holding a character that needs one of the Unicode foldings raises
  `RegexpError` rather than answering as if the character had no case.
- The regexp POSIX brackets classify by Unicode above ASCII: `[[:alpha:]]`
  holds a letter of any script and `[[:^alpha:]]` rejects it, as in CRuby.
  Without the gem a bracket holds its ASCII and no character above it.
- `String#succ` steps a letter or a digit above ASCII within its own run of
  them and wraps at the end of it, as in CRuby (`"ת".succ` is `"אא"`).
  Without the gem nothing above ASCII is a letter or a digit, and the last
  character steps as a character.
- `__ENCODING__` answers `"UTF-8"`, which is what the tests of several gems
  read to tell the two builds apart. Without the gem it answers
  `"ASCII-8BIT"`.

`MRB_USE_ASCII_CTYPE` narrows the case, the brackets and `String#succ` back to
ASCII, taking the refusal with them and leaving the indexing; see
[mrbconf.md](../../doc/guides/mrbconf.md) for what that buys.

## What it adds to Ruby

### `Encoding` Module

A module (not a class, unlike standard Ruby) that holds encoding constants.
Each constant is a frozen String naming an encoding rather than an `Encoding`
object.

- `Encoding::UTF_8`: Represents the UTF-8 encoding.
- `Encoding::ASCII_8BIT`: Represents the ASCII-8BIT encoding.
- `Encoding::BINARY`: An alias for `Encoding::ASCII_8BIT`.

### `String` Methods

- `string.valid_encoding? -> true or false`
  - Returns `true` if the string is correctly encoded (particularly useful for
    UTF-8 strings). For `ASCII-8BIT` strings, it generally returns `true`.
- `string.encoding -> EncodingConstant`
  - Returns the encoding of the string. This will be `Encoding::UTF_8` or
    `Encoding::BINARY`.
- `string.force_encoding(encoding_name) -> string`
  - Changes the string's reported encoding to the specified `encoding_name`
    (e.g., "UTF-8", "ASCII-8BIT", "BINARY").
  - The actual byte sequence of the string is not changed.
  - Raises an `ArgumentError` if an unsupported encoding name is provided.

### `Integer` Method

`Integer#chr` comes from mruby-string-ext, and the encoding argument it takes
reads the same names. With this gem in the build:

- `integer.chr(encoding_name = Encoding::BINARY) -> String`
  - Returns a single-character string represented by the integer.
  - If `encoding_name` is "UTF-8", the integer is treated as a Unicode
    codepoint.
  - If `encoding_name` is "ASCII-8BIT" or "BINARY" (the default), the integer
    is treated as a byte value (0-255).
  - Raises a `RangeError` if the integer is out of the valid range for the
    specified encoding.
  - Raises an `ArgumentError` for unknown encoding names. Without the gem
    "UTF-8" is one of those names.

## Usage Example

```ruby
s = "helloあ"
s.length          #=> 6
s.encoding        #=> "UTF-8"
s.valid_encoding? #=> true

# The bytes are left as they are; only what they are read as changes.
s2 = "\xE3\x81\x82"
s2.force_encoding("BINARY")
s2.encoding       #=> "ASCII-8BIT"
s2.length         #=> 3
s2.force_encoding("UTF-8")
s2.length         #=> 1

invalid = "\xff\xfe".force_encoding("UTF-8")
invalid.valid_encoding? #=> false

65.chr            #=> "A"        (ASCII-8BIT by default)
12354.chr("UTF-8") #=> "あ"
0x110000.chr("UTF-8") #=> RangeError
```
